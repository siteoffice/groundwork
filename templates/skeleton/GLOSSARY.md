# Glossary

The words this project uses, and what each one means here. Read it before using a term; add a
term when a decision settles it. One line per term, alphabetical.

| Term | Meaning |
|---|---|
| Approver | The one person whose yes is needed before money, a send, a publish or a delete. See `00_context/brief.md`. |
| Gate | A point in the one loop where a person decides. G1 plan, G2 spec, G4 ship, G3 learn. |
| Receipt | A local, self-issued, not signed record of an accepted change. |
