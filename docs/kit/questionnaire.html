Groundwork

Ten questions before anything gets builtTien vragen voordat er iets gebouwd wordt

About fifteen minutes. There are no wrong answers: shooting down a candidate answer is the most useful thing you can do. Your answers are saved in this browser as you type, so you can stop and come back. When done, press Export and send the file to info@zerononsense.dev. Ongeveer een kwartier. Er zijn geen foute antwoorden: een kandidaat-antwoord afschieten is het nuttigste wat je kunt doen. Je antwoorden worden tijdens het typen in deze browser bewaard, dus je kunt stoppen en terugkomen. Klaar? Druk op Exporteer en stuur het bestand naar info@zerononsense.dev.

The open floorVrije ruimte

Beyond these ten questions: describe your ideal solution and the features you want, in whatever format works for you. Text, a voice memo, a video, a sketch, a screen recording, all fine; send it however you like. If you can, mark each feature Must have, Should have or Nice to have (MoSCoW): that ordering decides what gets built first. Naast deze tien vragen: beschrijf je ideale oplossing en de features die je wilt, in de vorm die jou past. Tekst, een spraakmemo, een video, een schets, een schermopname, alles mag; stuur het zoals je wilt. Markeer features als het kan met Must have, Should have of Nice to have (MoSCoW): die volgorde bepaalt wat eerst gebouwd wordt.

How this worksZo werkt dit

Answer in steps, export onceAntwoord in stappen, exporteer een keer

  1. Answer what you can. Every question carries the candidate answers already worked out; pick one, pick several, or pick none and write your own. The free text field under each question is always there.Beantwoord wat je kunt. Elke vraag draagt de kandidaat-antwoorden die al bedacht zijn; kies er een, meerdere, of geen en schrijf je eigen antwoord. Het vrije tekstveld onder elke vraag is er altijd.
  2. Stop whenever you like. Everything is saved automatically in this browser, on this computer. Nothing is sent anywhere while you type. Come back tomorrow and it is still here (same browser, same machine).Stop wanneer je wilt. Alles wordt automatisch bewaard in deze browser, op deze computer. Er wordt niets verstuurd terwijl je typt. Kom morgen terug en het staat er nog (zelfde browser, zelfde machine).
  3. Export when done. The Export button creates a small markdown (.md) text file with your answers. Mail it to info@zerononsense.dev, or hand it to whoever coordinates. If the download does not work, use Copy and paste it into a mail.Exporteer als je klaar bent. De Exporteer-knop maakt een klein markdown (.md) tekstbestand met je antwoorden. Mail het naar info@zerononsense.dev, of geef het aan wie het verzamelt. Werkt de download niet, gebruik dan Kopieer en plak het in een mail.
  4. Add anything, in any format. Ideas and features that do not fit the questions: send text, audio, video, a sketch, whatever works. MoSCoW markers (Must, Should, Nice) help decide build order.Vul aan, in elk formaat. Ideeen en features die niet in de vragen passen: stuur tekst, audio, video, een schets, wat werkt. MoSCoW-markering (Must, Should, Nice) helpt de bouwvolgorde bepalen.

Why markdown: your answers arrive as a plain, readable file that can be analysed and compared directly, without retyping. The honest limit: answers live only in this browser until you export, so clearing browser data before exporting loses them. Waarom markdown: je antwoorden komen aan als een leesbaar, plat bestand dat direct geanalyseerd en vergeleken kan worden, zonder overtypen. De eerlijke grens: antwoorden staan alleen in deze browser tot je exporteert, dus browserdata wissen voor het exporteren gooit ze weg.
